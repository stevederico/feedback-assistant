Feedback Assistant — Widget Test Page

The floating button should appear in the lower-right corner.

How this page is wired

<script
  src="http://localhost:8000/widget.js"
  data-project="pk_..."
  data-api="http://localhost:8000/v1"
  defer
></script>

That's the entire embed. Submissions land in the dashboard (default http://localhost:5173). Replace data-project with your own pk_* from the Apps page. For production, point src / data-api at your deployed host (set companyWebsite in src/constants.json and CORS_ORIGINS / FRONTEND_URL in the server env).
